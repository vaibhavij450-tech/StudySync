# StudySync – Smart Study Planner

A web application to manage study tasks, track study time, and organise subjects.

## 🚀 Live Demo

**[Click here to open StudySync](https://study-sync-gules.vercel.app)**

## 🛠️ Tech Stack
- Frontend: React.js and Vite
- Backend: Node.js and Express.js
- Database: MongoDB Atlas
- DevOps: Docker and Jenkins CI/CD
- Deployment: Vercel and Render
